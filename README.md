# 🚀 منصة مساعد الإنتاجية الذكي (Smart AI Task Manager)

منصة ويب تفاعلية متكاملة (SaaS-Ready) لإدارة المهام والوقت، مصممة بهندسة برمجية متطورة تتيح التخصيص الكامل والديناميكي حسب دور المستخدم وسلوكه الفعلي، ومدعومة بالكامل بالذكاء الاصطناعي التوليدي والتحليلي.

---

## 🛠 البنية التقنية وهندسة النظام (System Architecture)

تم تصميم النظام ليعمل بكفاءة عالية على خوادم **WHM/cPanel** مع التجهيز الهيكلي للربط مع تطبيقات الهواتف الذكية (iOS & Android) مستقبلاً:

- **الخلفية (Backend):** Laravel (PHP 8.2+) مع نظام الجدولة الخلفية (Task Scheduler / Cron Jobs).
- **قاعدة البيانات:** MySQL / MariaDB مع دعم القيود المرجعية الآمنة والحذف الناعم (Soft Deletes).
- **الواجهة الأمامية (Frontend):** Tailwind CSS + DaisyUI لتقديم واجهات متجاوبة ومشبعة بالألوان.
- **التفاعل والتلميحات:** Alpine.js لبناء النوافذ والتلميحات الفورية السريعة.
- **التقويم والرسوم البيانية:** FullCalendar.js للتقويم، و Chart.js لإحصاءات الإنتاجية الملونة.
- **محرك الأوفلاين (Offline Engine):** Service Workers لإدارة الشبكة، و IndexedDB للتخزين المحلي.
- **بوابات الـ APIs الخارجية:** 
  - **OpenAI GPT API:** لمعالجة الجدولة وحل الازدحام وتحليل السلوك.
  - **Whisper API:** لتحويل الصوت إلى مهام مكتومة (Voice-to-Task).
  - **Firebase Cloud Messaging (FCM):** لإدارة الإشعارات الفورية على الهواتف والمتصفحات.

## 🌟 الدليل الشامل للميزات والوظائف (Detailed Features Directory)

### 1. الروتين اليومي الثابت وحظر الوقت (Time Blocking)
يحدد المستخدم أوقات روتينه الثابتة (مثل: أوقات النوم، الوجبات، العمل الأساسي، الدراسة الثابتة). يتعرف النظام والذكاء الاصطناعي على هذه الأوقات كـ **"مناطق مغلقة" (Locked Zones)** لا يقترح فيها مجدداً أي مهام، لضمان واقعية الجدولة واحترام طاقة المستخدم البشرية.

### 2. الجدولة الذكية ومكافحة الازدحام (Workload Conflict Resolution)
عند محاولة ترحيل أو تأجيل مهمة إلى "اليوم التالي" وكان هذا اليوم مزدحماً مسبقاً، يرفض النظام النقل المباشر، ويقوم الذكاء الاصطناعي تلقائياً بتحليل اليوم واقتراح 3 حلول بديلة تظهر في بطاقات اختيار:
- **تفكيك المهمة (Task Splitting):** تقسيم المهمة المُراد نقلها على يومين متتاليين.
- **التبديل الذكي (Task Swapping):** ترحيل مهمة ترفيهية أو أقل أهمية من اليوم المزدحم لإفساح مجال للمهمة الهامة.
- **استغلال الفجوات الزرقاء (Gap Finder):** جدولة المهمة في الفراغات البسيطة المتبقية خارج أوقات الروتين.

### 3. منقذ التسويف والمهام العالقة (Procrastination Rescue)
يقوم النظام بتتبع عمليات تأجيل المهام. بمجرد وصول عداد تأجيل مهمة معينة إلى (3 مرات متتالية)، يتدخل الذكاء الاصطناعي تلقائياً لتفكيك المهمة الصعبة إلى 4 مهام فرعية متناهية الصغر (لا تتطلب كل منها أكثر من 10 دقائق) لكسر حاجز الخوف والتسويف لدى المستخدم.

### 4. الإدخال الصوتي الذكي (Voice-to-Task)
بضغطة زر واحدة، يستطيع المستخدم تسجيل موعده أو مهمته بصوته. يرسل النظام الملف الصوتي إلى **Whisper API** لتحليله وتحويله لنص، ثم استخلاص: العنوان، التصنيف، الأهمية، والتاريخ المقدر، لملء حقول الإضافة تلقائياً أمام أعين المستخدم.

### 5. نظام التذكير المخصص والمتكرر (Customizable Reminders)
يمكن للمستخدم تخصيص تردد التنبيهات لكل مهمة بشكل مرن (تنبيه لمرة واحدة، كل ساعة، كل يوم، كل أسبوع، كل شهر). يعمل محرك الفحص الخلفي (Laravel Cron Job) على معالجة التكرار بدقة تامة دون التأثير على موارد السيرفر.

### 6. واجهة الإرشاد والتلميحات التفاعلية (Hover Tooltips & UI)
تطبيق تجربة مستخدم مبسطة وجذابة تدعم الوضعين الداكن والفاتح بانتقالات سلسة:
- **تلميحات الـ Hover التفاعلية:** بجانب كل حقل أو خيار معقد، توجد أيقونة استفهام متوهجة. بمجرد مرور مؤشر الفأرة عليها، تنبثق فقاعة نصية منسقة (Popover) تشرح الحقل بأسلوب مبسط جداً لتقليل ارتباك المستخدم.
- **شريط النصائح اليومي:** يعرض شريط صغير أعلى لوحة التحكم نصيحة إنتاجية ذكية وقصيرة متجددة كل 24 ساعة.

### 7. العمل دون اتصال والمزامنة (Offline-First)
يتيح التطبيق إدارة المهام (إضافة، تعديل، حذف، تصفح) بكفاءة كاملة عند انقطاع الإنترنت بالاعتماد على قاعدة بيانات المتصفح **IndexedDB**، وفور عودة الإشارة، يزامن النظام كافة التغييرات مع قاعدة البيانات السحابية (MySQL) في الخلفية تلقائياً دون تشتيت المستخدم.

## 👑 خصائص لوحة تحكم الأدمن الديناميكية (Dynamic Admin Dashboard)

- **إدارة المسميات والأدوار:** إمكانية تعديل وتحديث وحذف أدوار المستخدمين (طالب، موظف، مدير...) بشكل مرن ينعكس على الواجهات والترجمات فوراً.
- **الحقول المخصصة ديناميكياً:** تحديد حقول إضافية معينة (عبر حقول JSON) تظهر وتختفي عند إنشاء المهام بناءً على دور المستخدم الحالي.
- **التحكم بنبرة الذكاء الاصطناعي (Prompt Tuning):** حقل مخصص للأدمن لتعديل وتوجيه الـ System Prompt الخاص بالذكاء الاصطناعي لكل دور لتخصيص أسلوب الردود.
- **إدارة استهلاك الـ API والتحكم بالتكلفة:** تحديد نظام نقاط واستهلاك يومي (Token Limits) لكل دور مستخدم لحماية خادمك من التكاليف المادية المرتفعة.
- **أمان وتكامل البيانات عند الحذف:** منع الأدمن من حذف أي قسم أو دور مرتبط ببيانات نشطة للمستخدمين إلا بعد إعادة توجيه تلك البيانات أو نقلها، مع دعم كامل للـ Soft Deletes.
- **النسخ الاحتياطي التلقائي:** جدولة أخذ نسخ احتياطية كاملة لقاعدة البيانات والملفات وحفظها بأمان.

## 📅 خطة ومراحل التنفيذ الهندسية بالتفصيل الممل (Implementation Roadmap)

### 📌 المرحلة الأولى: التأسيس، الأمان وبنية البيانات الديناميكية (الأسبوع 1-2)
- [ ] **إعداد السيرفر:** تثبيت وتهيئة Laravel 11 وتفعيل PHP 8.2 واستصدار شهادة الأمان SSL الآمنة على السيرفر.
- [ ] **بناء قاعدة البيانات:** تشغيل وإنشاء جداول قاعدة البيانات المرجعية (الأدوار، المستخدمين، الجهات، المهام، الروتين الثابت) مع تفعيل العلاقات المرجعية الآمنة.
- [ ] **نظام الحسابات:** بناء نظام تسجيل الدخول والتحقق القياسي مع إلزامية تحديد دور المستخدم الأساسي لتهيئة ميزات التخصيص.

### 📌 المرحلة الثانية: واجهات المستخدم، التلميحات والأوفلاين (الأسبوع 3-4)
- [ ] **تصميم الواجهات:** تطبيق تصميم Tailwind المتجاوب ذو الألوان المشبعة البراقة ودعم الوضع الليلي والنهاري.
- [ ] **نظام التلميحات:** بناء وتوزيع تلميحات الـ Hover التفاعلية عبر Alpine.js وشريط نصائح الإنتاجية المحدث يومياً.
- [ ] **التقويم والمهام:** ربط المهام بواجهة التقويم التفاعلي (FullCalendar.js).
- [ ] **محرك الأوفلاين:** برمجة وتثبيت ملفات الـ Service Worker وقاعدة IndexedDB المحلية ونظام المزامنة التلقائية عند عودة الاتصال.

### 📌 المرحلة الثالثة: دمج عقل النظام والذكاء الاصطناعي والإدخال الصوتي (الأسبوع 5-6)
- [ ] **ربط الـ APIs:** تهيئة ربط Laravel بـ APIs شركة OpenAI وتأمين مفتاح الوصول في الخادم.
- [ ] **محرك الجدولة الثابتة:** بناء صفحة إدخال الروتين اليومي وحظر الوقت وربطها بخوارزمية فحص الازدحام.
- [ ] **منقذ التسويف:** تفعيل تتبع عداد تأجيل المهام وتجهيز خطط تفكيك المهام الصغيرة عبر الذكاء الاصطناعي.
- [ ] **الإدخال الصوتي:** دمج ميزة التسجيل الصوتي وربطها بـ Whisper API لاستخلاص بيانات المهام تلقائياً.

### 📌 المرحلة الرابعة: لوحة تحكم الأدمن الشاملة والتقارير والنسخ (الأسبوع 7-8)
- [ ] **تثبيت لوحة الأدمن:** بناء لوحة التحكم الديناميكية الشاملة باستخدام Filament.
- [ ] **أمان قاعدة البيانات:** تفعيل ميزة منع الحذف العشوائي والنوافذ التحذيرية الذكية (Safety Deletion Constraints).
- [ ] **التحكم بالنقاط والـ Prompts:** بناء واجهات تعديل نبرة الذكاء الاصطناعي وإدارة نقاط الاستهلاك اليومية ومراقبة التكلفة المادية.
- [ ] **التقارير الرسومية والتصدير:** بناء واجهة الرسوم البيانية (Chart.js) وبرمجة أدوات التصدير لملفات PDF و Excel.
- [ ] **النسخ الاحتياطي:** تفعيل وجدولة النسخ الاحتياطي التلقائي لقواعد البيانات والملفات.

### 📌 المرحلة الخامسة: الإطلاق الرسمي والتكامل مع تقويم الهاتف (الأسبوع 9)
- [ ] **الربط بالتقويم الافتراضي:** برمجة توليد ملفات ICS لإتاحة تصدير المهام مباشرة لتقاويم هواتف Apple و Google.
- [ ] **اختبارات الجودة:** إجراء فحص شامل للأمان، وحماية المدخلات، وضبط الكاش لرفع كفاءة التصفح والأداء.
- [ ] **تأهيل مسارات الـ API:** اختبار وتجهيز وتوثيق مسارات الـ API بالكامل لتكون المنصة مهيأة تماماً للربط الفوري بتطبيق جوال أصيل (Flutter/React Native) مستقبلاً.

## 💾 استراتيجية النقل السلس بين السيرفرات (Portability & Migration Guide)

لضمان إمكانية نسخ هذا النظام بالكامل ونقله من خادم لآخر أو من نطاق لنطاق في دقائق معدودة، تم اتباع المعايير البرمجية التالية:
1. **عزل المتغيرات البيئية:** يتم حفظ كافة الروابط الحساسة ومفاتيح قواعد البيانات والـ APIs في ملف الإعدادات المتغير `.env` المعزول.
2. **بناء الجداول بلمحة بصر:** لا يتم استخدام ملفات SQL يدوية، بل يتم الاعتماد على الـ Migrations والـ Seeds لبناء الهيكل وتعبئته برمجياً بضغطة زر.
